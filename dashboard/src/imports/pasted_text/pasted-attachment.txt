# Figma AI Prompts — Aitbaar Applicant Web Portal + Officer Dashboard

Use with Figma **First Draft** (design file → ✨ AI icon / `Ctrl+/` → "First Draft").
Each block below is self-contained — copy one whole block, paste it into the
First Draft prompt box, set the platform toggle as noted, and generate.
Do this once per block (each generation is a fresh one-shot request, it does
not remember earlier ones).

Order: generate A → F for the applicant portal, then G → I for the officer
dashboard. Drop all resulting frames onto one Figma page afterward, in that
order, and add a cover frame with team name + "UBL National Innovation
Hackathon 2026 — AI in Banking" for the submission export.
